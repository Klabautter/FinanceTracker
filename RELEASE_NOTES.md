Widgets, Siri and plain-language questions, a faster app for large histories, and many fixes for amounts, imports and backups.

- **Widgets:** A small and a medium widget show what you can still spend this month and the budgets that need attention. Privacy mode hides the amounts there too.
- **Questions in plain language:** Type a question such as "How much on restaurants this summer?" into the command palette to get the total and the transactions behind it; each one opens from there. Split transactions count with the matching part, as in analytics. If a question names no category, the language model on your Mac, where available, maps the wording to one of your categories; it sees no transactions and the total is always computed by the app. Shortcuts and Siri answer "Spending This Month" and "Available Until Month End".
- **Forecast what-if:** The month-end card lists the payment plans still due. Untick one or enter a trial amount to see what would be available and how long your total balance would then last. Nothing is saved.
- **Noticed:** The overview points out possible double charges, subscriptions that got more expensive, unusually high amounts at a known merchant and budgets that will run out at the current pace. Each notice can be dismissed.
- **Base currency:** Choose the currency for totals, budgets and the forecast in Settings. Accounts keep their own currency.
- **Appearance:** Choose System, Light or Dark in Settings.
- **Receipts:** Attach PDFs and images to a transaction in its detail view, or drag them in from the Finder. A removed receipt and a deleted group share can be brought back right afterwards.
- **Drag and drop:** Drop a CSV, Excel file or PDF statement anywhere on the window or on the Dock icon to open the import with it. The Enable Banking key file can be dropped into its field.
- **Working with many transactions:** Right-click a selection to set category, tags, review state or analytics for all of it; the selection stays after bulk actions. The Delete key removes the manually entered transactions of a selection in one undoable step and leaves bank transactions alone. Command-Z in text fields undoes typing again.
- **Large histories:** With 100,000 transactions the overview appears in about a quarter of a second, switching months is instant, search answers in well under a second and the app needs a fraction of the memory it used before. A 20,000-row import is several times faster.
- **Amounts:** Every amount field, including new transactions, splits and group shares, follows your number format, so 1.500 means fifteen hundred in German, and shows how the input was read. CSV files whose amounts are ambiguous ask once instead of guessing, using an amount from the file and both readings spelled out. A CSV with a quotation mark that is never closed is reported as damaged.
- **Bank bookings:** Bookings without a booking date use the value date; rows without any readable date are reported instead of being stored with the sync time. Bank errors now name the likely cause and the next step.
- **Bank sync:** A sync compares new bookings only with the part of the account they can match instead of loading the whole account, which keeps it quick on long histories.
- **Bank sign-in:** If financetracker://bank-callback is added as a redirect URL of your Enable Banking application, the sign-in returns straight to the app. Otherwise nothing changes. The app accepts only the return that belongs to the sign-in it started.
- **Forecast:** A manually entered salary plan is no longer counted twice.
- **Recurring payments:** Fuel and grocery stops are no longer suggested as monthly payments.
- **Backups:** A backup can be protected with a password; it is then encrypted and cannot be restored without it. Backups without receipts restore again, and every backup is checked against the restore rules before it is saved. Undoing an import now removes everything attached to its transactions, so later backups restore again. Leftovers from earlier undos are cleaned up on launch. Backups no longer contain the bank session ID.
- **Delete All Data:** Settings can remove all finance data on this Mac after writing a full backup first.
- **Privacy:** Logs keep account and session identifiers private, bank requests use no disk cache, and CSV exports can no longer be run as spreadsheet formulas.
- **Narrow windows:** Tables keep the amount column fully visible, analytics filters wrap, and the detail pane can be resized.
- **Accessibility:** Green, red, orange and blue text is darker in light mode and now meets the WCAG AA contrast level on every surface. Stronger lines with Increase Contrast, and VoiceOver reads the values of the spending pace chart.
- **Notices:** Error notices in tags, categories, review and collections disappear with the next action and can be closed.
- **English:** The whole interface is now available in English, including the Siri phrases.
- **Data:** The database gets an index for faster queries; the update migrates it automatically on first launch.
