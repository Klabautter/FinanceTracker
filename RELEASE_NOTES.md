PDF statements now also set the account balance when it is only stated in the header.

- Many statements give the balance only in a line such as "Balance on 30/09/2026" instead of a balance column. The import now reads these lines in English and German and uses the latest one, so savings and clearing accounts imported from monthly PDF statements show up in the total balance.
- Statements with a balance column work as before. Available amounts that may include an overdraft, lines in another currency and conflicting values are not used.
