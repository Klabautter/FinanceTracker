A smarter file import that understands what each transaction is, from any bank or card.

- Transaction types such as card payments, top-ups, currency exchanges, refunds, cashback, fees, interest and securities trades are recognised in English and German, without bank-specific setup.
- Unknown transaction types are listed in the import preview and can be assigned once per account; the app remembers your choice.
- Fees in their own column become separate fee transactions, and amounts in the merchant's currency are kept as the original amount.
- The preview shows how each transaction will count, for example as a transfer or cashback.
- Transactions already in an account are no longer imported twice, whether they came from another file format (PDF, CSV, Excel) or from bank sync.
- When bank sync delivers a transaction that was imported from a file before, the existing entry is updated instead of duplicated; categories, notes, tags and receipts stay.
- A pending transaction is updated once the booked version arrives, even from a different source.
