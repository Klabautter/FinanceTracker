The app is now notarized by Apple and opens without a warning; open recurring payments and the period comparison are more accurate.

- **Notarized by Apple:** FinanceTracker is now signed with an Apple Developer ID and notarized, so macOS opens it on first launch without "Open Anyway". Because the signature changes with this update, macOS may ask once more for access to the keychain entry with your Enable Banking key, and possibly for access to the app's data. Allow it; afterwards updates install without these questions.
- **Recurring payments:** An overdue payment stays in the upcoming list until the end of the month instead of disappearing after seven days, so "Noch offen" always matches the payments listed below it.
- **Analysis:** "% vs. Vorperiode" only appears when every account with spending in the current period also has data for the previous one. An account added later, for example a newly connected bank, no longer shows up as a large increase in spending.
- **Accounts:** The note that foreign-currency bookings are not included only appears when they are really missing from the shown balance. Bookings already covered by a statement or bank balance no longer trigger it.
